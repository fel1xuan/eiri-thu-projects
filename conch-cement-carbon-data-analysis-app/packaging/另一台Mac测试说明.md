# 另一台 Mac 测试说明

## 测试版本

当前测试App：

```text
dist/清华数据分析软件.app
```

内部版本为 `1.0.0`，界面显示“詹宇轩1.0版”。当前测试App只支持 Apple Silicon arm64 Mac。请先确认另一台 Mac 的芯片架构，不要在 Intel x86_64 Mac 上直接当作已支持版本使用。

## 复制和解压

1. 如需复制到另一台Mac，先使用macOS `ditto` 将完整 `.app` 打成zip，以保留bundle属性。
2. 将zip复制到另一台Mac后双击解压，得到：

```text
清华数据分析软件.app
```

3. 建议先放在普通用户目录中测试，例如“下载”或“桌面”，不需要放入系统目录。

## 第一次打开

这是本机测试版，只有 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证。

如果 macOS 提示“无法验证开发者”：

1. 在 Finder 中右键 `清华数据分析软件.app`。
2. 选择“打开”。
3. 在弹窗中再次确认“打开”。

不建议关闭系统安全设置，不要使用 `sudo`，不要移除系统安全机制。

## 基础冒烟测试

打开 App 后检查：

1. Dock 中出现 App。
2. 主窗口标题是“清华数据分析软件”。
3. 不是浏览器窗口。
4. 不启动 localhost 或 127.0.0.1。
5. 没有额外终端窗口。
6. 版本号显示正常。
7. 窗口不崩溃。

逐个点击左侧7个页面：

1. 工作台
2. 项目配置
3. 0号 日报提取与审核
4. 一键运行
5. 结果查看
6. 运行记录
7. 使用说明

确认页面可切换、标题正确、文字没有严重重叠、按钮和输入框正常显示。结果查看应包含“结果文件”和“15min图表查看”两个Tab，使用说明应显示两张思维导图。

## 文件选择器测试

只测试选择器，不点击任何运行按钮。

在“项目配置”页面测试：

1. 数据项目根目录选择文件夹。
2. 生产综合日报选择文件。
3. 历史低频主表选择文件。
4. 当月低频数据选择文件夹。
5. 秒级/高频数据目录选择文件夹。
6. 输出目录选择文件夹。

确认 Finder 选择器可以弹出、中文路径正常显示、取消不会崩溃、选择后路径能写入输入框。

## 配置和日志位置

配置和日志保存在当前 Mac 用户自己的 Library 目录中：

```text
~/Library/Preferences/清华数据分析软件/app_config.json
~/Library/Application Support/清华数据分析软件/run_log.csv
```

正式 Excel 和图表结果不会写入 App 内部，也不再使用统一 `output_dir`。软件根据数据项目根目录自动写入：当月低频目录、低频数据根目录、`2.秒级核算数据`、`3.秒级异常数据统计` 和 `4.15min核算数据`。

## 不要直接整月运行

另一台 Mac 第一轮只做页面冒烟测试和文件选择器测试。

不要直接运行 2026-05 整月流程。
不要点击“一键运行”的确认继续。
不要运行 0/1/2/3 业务计算。

如果必须测试运行按钮，只点击按钮后在确认弹窗中选择“否”，确认不会执行计算。

## 反馈信息

如果启动失败或页面异常，请反馈：

1. macOS 版本。
2. 芯片架构。
3. App 所在路径。
4. 弹窗错误截图。
5. 是否出现“无法验证开发者”。
6. 是否能右键打开。
7. 哪个页面或按钮出错。

查看系统版本和芯片架构：

```bash
sw_vers
uname -m
```
